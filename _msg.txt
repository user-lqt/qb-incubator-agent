feat(web): 对话自动存档，刷新/关闭后可恢复（含界面、状态、轮次）

需求：刷新页面时不想丢进度。

- agent.js：新增 serialize()/restore()（对话记录 + 局内状态，带 schema 版本号，
  旧结构存档会被安全拒绝）
- index.html：每轮结束自动写入 localStorage（界面气泡、选项、四维状态、轮次、结局横幅）；
  载入时若检测到存档，先恢复界面与状态条，再提示"已恢复上次对话（N 分钟前，第 X 轮）"，
  不再重播序章
- 没填 API key 时也能恢复界面：会话先挂在 pendingSession，等填入 key 后自动灌进 client
- 「重新开始」会同时清掉本机存档与待恢复会话
- 版本提示行注明"对话自动保存在本机，刷新可恢复"

顺带修复（用户反馈"有时不显示选项"）：
- 选项被脏数据过滤后为空时，先前直接不渲染 -> 现在回退到兜底话术，
  界面永远有可点选项（agent.js 用 sanitizeChoices，index.html 再做一次兜底）

实测（无头 Chrome + 本地 HTTP，真实 localStorage）：
  有存档：恢复提示 ✅ 气泡 ✅ 我的消息 ✅ 选项按钮 ✅ 状态条 契约42/第5轮 ✅ 不重播序章 ✅
  清档后：正常播放序章 ✅ 无恢复提示 ✅
回归测试：两侧新增存档往返与旧 schema 拒绝断言
